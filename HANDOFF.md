## Как читать макеты

- Каждая страница самодостаточна: инлайн-стили секций + общие ассеты из `assets/`.
- Хром сайта (сайдбар, топбар, промо) — только контекст: верстается **контент-зона**, хром продовый.
- Все интерактивы в макетах рабочие: пересчёт цен по периодам, чекауты, слайдер персонажа, FAQ, тултипы. Переходы к платёжным провайдерам имитируются тостом — в проде это редиректы (см. спеки).
- Мобильные раскладки смотрятся сужением окна: брейкпоинты описаны в спеках.

## Дизайн-система

- `assets/lovix.css` — токены, извлечённые из продакшн-CSS lovix.ai. **Маппинг макетных переменных на прод-переменные** — `price/SPEC.md` раздел 2; при вёрстке использовать продовые.
- Шрифт — продовый Proxima Nova (Mulish в макетах — только фолбэк превью).
- Иконки — инлайн SVG-спрайт в каждой странице (feather-стиль, stroke 2); кристалл токена и логотип — фирменные path'ы из спрайта.

## Переиспользуемые компоненты

При вёрстке выносятся в общие (в макетах стили продублированы по страницам намеренно — ради самодостаточности файлов):

1. **Чекаут-оверлей** (`.ck-*`) — один компонент с двумя наполнениями: подписка (тариф + сегмент периода + сводка с выгодой) и пакет (номинал + цена). Закрытие: ✕ / клик по фону / Esc.
2. **Выбор способа оплаты** — радио-строки `.ck-opt` (Карта РФ / Карта Worldwide / Криптовалюта) с логотипами `#p-*`; в проде заменить макетные SVG брендовыми ассетами платёжных систем.
3. **Карточка** (`.plan` / `.pack`): фон `rgba(16,14,16,.55)` + blur, радиус 1.1rem; выделенная — градиентная рамка (padding-box/border-box) + бейдж-пилюля + свечение.
4. **Сегмент-переключатель** (`.seg`) — активный сегмент градиентная пилюля.
5. **FAQ-аккордеон** (`.faq`, нативные `details/summary`, плюсик с поворотом).
6. **Слайдер персонажа** (`.muse-card` + `assets/muse-slider.js`): автоплей 5с, пауза hover, стрелки/точки, синхронизация имени через `data-name`.
7. **Toast** — в проде не нужен (заглушка редиректов).

## Данные из настроек (не хардкодить)

- Цены тарифов и скидки периодов: `assets/pricing.js` (`PRICING`, `SAVE`) — производные от `PREMIUM_PRICE_1M=990`, `VIP_PRICE_1M=1590`, `PERIOD_DISCOUNT_3M=10%`, `PERIOD_DISCOUNT_1Y=20%`. Итоговые суммы и строки — таблица в `price/SPEC.md` раздел 4.
- Номиналы и цены пакетов: `assets/packs.js` (`PACKS`) — значения предварительные.
- Объёмы токенов (300/550) одинаковы для всех периодов — правило Т10.
- Тексты карточек и FAQ зафиксированы токеномикой — менять только вместе с ней.

## Интеграция (сводно, детали в спеках)

- **Роутинг оплаты**: `ru` → эквайринг РФ, `world` → международный, `crypto` → крипто-процессинг. В редирект: тариф+период (или пакет) + способ.
- **Дефолт способа**: запомненный успешный способ из профиля → иначе гео (RU-IP → Карта РФ). Выбор всегда видим (аудитория под VPN).
- **Recovery-петля**: возврат без успешной оплаты → чекаут переоткрывается с баннером «Не получилось? Попробуйте другой способ» и альтернативным способом.
- **Доступ**: страница пакетов — только платным (П5), в дни 1–4 просрочки покупка пакета недоступна (П7); действующие Legacy-подписчики новую сетку тарифов не видят (раздел 10 токеномики).
- **Фото персонажей**: webp-вырезы с альфой ~400×861 и имена — из каталога компаньонов (в макете плейсхолдеры `assets/img/model-1.webp`, `model-2.webp`).
- **Аналитика**: списки событий — в спеках (раздел 7 у тарифов, раздел 7 у пакетов).
