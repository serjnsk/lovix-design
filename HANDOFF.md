## Как читать макеты

- Каждая страница самодостаточна: инлайн-стили секций + общие ассеты из `assets/`.
- Хром сайта (сайдбар, топбар, промо) — только контекст: верстается **контент-зона**, хром продовый.
- Все интерактивы в макетах рабочие: пересчёт цен по периодам, чекауты, слайдер персонажа, FAQ, тултипы, панель уведомлений со всеми флоу. Переходы к платёжным провайдерам имитируются тостом — в проде это редиректы (см. спеки).
- В макете уведомлений внизу страницы — демо-панель симуляции (прилёт события, grace-окно, очистка): только для проверки флоу, в прод не идёт.
- В макете чата кнопка подписки в топбаре — демо-циклер тарифа Free → Premium → VIP (обновляет замки Spicy, VIP-гейты и разлочку видео): в прод не идёт, тариф приходит из профиля.
- Мобильные раскладки смотрятся сужением окна: брейкпоинты описаны в спеках.

## Дизайн-система

- `assets/lovix.css` — токены, извлечённые из продакшн-CSS lovix.ai. **Маппинг макетных переменных на прод-переменные** — `price/SPEC.md` раздел 2; при вёрстке использовать продовые.
- Шрифт — продовый Proxima Nova (Mulish в макетах — только фолбэк превью).
- Иконки — инлайн SVG-спрайт в каждой странице (feather-стиль, stroke 2); кристалл токена и логотип — фирменные path'ы из спрайта.

## Переиспользуемые компоненты

При вёрстке выносятся в общие (в макетах стили продублированы по страницам намеренно — ради самодостаточности файлов):

1. **Чекаут-оверлей** (`.ck-*`) — один компонент с двумя наполнениями: подписка (тариф + сегмент периода + сводка с выгодой) и пакет (номинал + цена). Закрытие: ✕ / клик по фону / Esc.
2. **Выбор способа оплаты** — радио-строки `.ck-opt` (Карта РФ / Карта Worldwide / Криптовалюта) с логотипами `#p-*`; в проде заменить макетные SVG брендовыми ассетами платёжных систем.
3. **Карточка** (`.plan` / `.pack`): фон `rgba(16,14,16,.55)` + blur, радиус 1.1rem; выделенная — градиентная рамка (padding-box/border-box) + бейдж-пилюля + свечение.
4. **Сегмент-переключатель** (`.seg`) — активный сегмент градиентная пилюля.
5. **FAQ-аккордеон** (`.faq`, нативные `details/summary`, плюсик с поворотом).
6. **Слайдер персонажа** (`.muse-card` + `assets/muse-slider.js`): автоплей 5с, пауза hover, стрелки/точки, синхронизация имени через `data-name`.
7. **Центр уведомлений** — дропдаун-панель `.npanel` (шапка «прочитать все»/настройки, группы «Новые/Ранее», подэкран настроек категорий), элемент `.nitem` (иконка-плашка по типу события `NCLASS`/`NICON`, hover-действия, точка непрочитанного, CTA → чип «✓ Готово»), критичный закреплённый блок `.ncrit` с таймером, бейдж колокольчика с пульсом и «9+».
8. **Виджет проактива компаньона** (`.lwdock`/`.lw`/`.lw-stack`) — «онлайн-чат» справа-снизу для `companion.proactive_sent`: развёрнутый баббл последнего проактива (аватар с пульсом, имя, реплика, «Ответить», ✕) + стопка круглых аватаров остальных ботов с непрочитанным (клик разворачивает). Мимо колокольчика, непрочитанное — бейдж `.sbcnt` на «Мои чаты». Поведение — `notifications/FLOWS.md` Флоу 8.
9. **Toast** — в проде остаётся только undo-тост удаления уведомления («Вернуть»); тосты-заглушки редиректов не верстаются.
10. **Композер чата** (`.composer`) — поле и действия в одном блоке: textarea сверху (min-height 64, авторасширение), строка `.crow` снизу: чипы `.qchip` (Фото / Голосовое / Видео `VIP` / Сценарии, без цен) + отправка. Режим запроса: чип `.on`, placeholder-подсказка, **цена в кнопке отправки** `.send.pricey` (`➤ 25 💎`), списание после ответа бота. Видео — только по пресетам (поповер «Видео по пресету»).
11. **Сообщения ленты чата** (`.m`/`.bub`) — текст с ремарками `.rp-act`, запрос `.reqhead`, фото `.phbox`, голосовое-плеер `.vc` (без транскрипта), видео `.vidbox` (заблюрено+замок для не-VIP / `.unlocked` для VIP), ошибка `.errb` с ретраем, «печатает» `.typing`, разделители `.dv`; фон ленты по режиму `.ccbg.rp`/`.ccbg.chat`.
12. **Пейволл-карточка в ленте** (`.payw`) — три наполнения: нехватка токенов (пакеты), VIP-гейт (звонок/видео), spicy-гейт (подписка для Free). Продажа на месте, без увода из чата.
13. **Просмотрщик медиа** (`.lb` + `.lbnav`/`.lbcnt`/`.vov`) и модалка **«Все медиа»** (`.mall`) — галерея с листанием (стрелки, ←/→, по кругу) и счётчиком; видео-слайды: play для VIP, замок + CTA «Перейти на VIP» для остальных; сетка профиля «Медиа чата»: до 6 превью, дальше тайл «+N» → «Все медиа»; пополняется медиа из диалога.

## Данные из настроек (не хардкодить)

- Цены тарифов и скидки периодов: `assets/pricing.js` (`PRICING`, `SAVE`) — производные от `PREMIUM_PRICE_1M=990`, `VIP_PRICE_1M=1590`, `PERIOD_DISCOUNT_3M=10%`, `PERIOD_DISCOUNT_1Y=20%`. Итоговые суммы и строки — таблица в `price/SPEC.md` раздел 4.
- **Прайс мультивалютный**: валюта привязана к способу оплаты (Карта РФ → RUB; Worldwide и Крипта → USD). Не курсовой пересчёт — у каждой валюты свой хардкод с маркетинговыми значениями: `PRICING_USD`/`SAVE_USD` в `pricing.js`, `priceUsd` в `packs.js`; таблицы — в спеках. Смена способа в чекауте мгновенно подменяет все суммы.
- Номиналы и цены пакетов: `assets/packs.js` (`PACKS`) — значения предварительные.
- Объёмы токенов (300/550) одинаковы для всех периодов — правило Т10.
- Тексты карточек и FAQ зафиксированы токеномикой — менять только вместе с ней.
- Тексты и состав уведомлений — контент-слой документа «Сценарии» (связка по ID сценария УX-X); демо-данные и маппинг иконок по типам — `assets/notifs-data.js`.
- Цены операций чата (фото 25 / голосовое 15 / видео 50 токенов) — прайс-лист настроек; видео-пресеты и сценарии «С чего начнём?» (Обычные/Spicy) — контент из настроек продукта.

## Интеграция (сводно, детали в спеках)

- **Роутинг оплаты**: `ru` → эквайринг РФ, `world` → международный, `crypto` → крипто-процессинг. В редирект: тариф+период (или пакет) + способ.
- **Дефолт способа**: запомненный успешный способ из профиля → иначе гео (RU-IP → Карта РФ). Выбор всегда видим (аудитория под VPN).
- **Recovery-петля**: возврат без успешной оплаты → чекаут переоткрывается с баннером «Не получилось? Попробуйте другой способ» и альтернативным способом.
- **Доступ**: страница пакетов — только платным (П5), в дни 1–4 просрочки покупка пакета недоступна (П7); действующие Legacy-подписчики новую сетку тарифов не видят (раздел 10 токеномики).
- **Фото персонажей**: webp-вырезы с альфой ~400×861 и имена — из каталога компаньонов (в макете плейсхолдеры `assets/img/model-1.webp`, `model-2.webp`).
- **Колокольчик**: канал сопровождения без квот и тихих часов, идут все Т+М; идемпотентность по ID события (С3); конверсия останавливает серию и переводит CTA в «✓ Готово» (Д2) со сверкой состояния с сервером; категории М отключаемы, Т — нет (Д7); критичное окно восстановления (У4) снимается только оплатой. Полные флоу, бейдж-правила и таблица «сценарий → CTA → маршрут» — `notifications/FLOWS.md`.
- **Чат — тарифные гейты**: Spicy-сценарии — только Premium/VIP (Free видит замки, клик — пейволл подписки); звонок и видео — только VIP (иначе VIP-гейт); видео-сообщения в истории разлочиваются тарифом. Списание токенов за запросы — после успешного ответа; сбой — возврат и «Повторить» (У3-7). В переходах из пейволлов передаётся точка входа.
- **Аналитика**: списки событий — в спеках (раздел 7 у тарифов и пакетов, «Аналитика» в FLOWS.md уведомлений и chat/SPEC.md §10).

- [ ] Слайдер персонажа: автоплей 5с, пауза при hover, стрелки и точки работают, имя меняется со слайдом
- [ ] Тултип «Групповые чаты» — по hover и focus
- [ ] Брейкпоинты: 1230 (муза-карточка на всю ширину ряда), 940 (одна колонка, выделенная карточка первой)
- [ ] FAQ-аккордеоны открываются/закрываются, плюсик поворачивается
- [ ] Free: CTA «Начать бесплатно» ведёт в регистрацию без чекаута; страница пакетов Free-пользователю недоступна
- [ ] Способ оплаты: дефолт по правилам, смена радио меняет провайдера редиректа
- [ ] Валюта: выбор «Worldwide» или «Крипта» подменяет все суммы чекаута на USD-прайс (и обратно на ₽ для «Карта РФ»); значения совпадают с таблицами в спеках
- [ ] Уведомления: бейдж считает непрочитанные (свыше девяти — «9+»), открытие панели бейдж не сбрасывает, клик читает; hover-действия и undo-удаление работают; CTA превращается в «✓ Готово»; критичный блок не сбрасывается «прочитать все» и снимается только оплатой; переключатели категорий скрывают М-уведомления мгновенно
- [ ] Виджет проактива: появляется справа-снизу с пульсом; несколько ботов складываются в стопку аватаров (развёрнут последний, клик по кружку разворачивает его); «Ответить»/аватар ведут в чат и убирают бота из стека, ✕ сворачивает в стопку с сохранением бейджа на «Мои чаты», колокольчик не затрагивается
- [ ] Чат: переключатель Roleplay/Чат один (в шапке), смена режима меняет фон ленты и добавляет разделитель
- [ ] Чат: клик «Фото»/«Голосовое» включает режим описания (чип подсвечен, placeholder меняется), цена появляется в кнопке отправки; повторный клик и Esc отменяют; списание — после ответа бота, баланс в топбаре обновляется
- [ ] Чат: «Видео» на VIP открывает пресеты и шлёт запрос без описания; на Free/Premium — VIP-гейт; видео-сообщения в ленте заблюрены с замком для не-VIP и разлочены для VIP
- [ ] Чат: новый чат открывается с приветствием и развёрнутым блоком сценариев; на Free spicy-таб и карточки с замками, клик — пейволл подписки; на Premium/VIP hover по spicy сыплет перчики
- [ ] Чат: при нехватке токенов на запрос — пейволл «Не хватает N» с пакетами, режим запроса не сбрасывается
- [ ] Чат: ошибка ответа показывает возврат токенов и «Повторить»; ретрай перезапрашивает ответ
- [ ] Чат-профиль: порядок фото → имя+возраст → описание → медиа → кнопки («Профиль» / «Перегенерировать»+«Редактировать») → факты; всё до фолда на 1440×900
- [ ] Чат-медиа: сетка до 6 превью, дальше «+N» → модалка «Все медиа»; клик миниатюры открывает просмотрщик с листанием (стрелки/клавиши, по кругу) и счётчиком; видео-слайд — play на VIP, замок + «Перейти на VIP» на остальных; медиа из новых сообщений появляются в сетке первыми
