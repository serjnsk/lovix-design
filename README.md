# Lovix Design

Редизайны страниц [lovix.ai](https://lovix.ai) под новую бизнес-логику.

**Live:** https://serjnsk.github.io/lovix-design/

## Структура

- `index.html` — хаб проекта: список страниц
- `price/` — **финальная** страница тарифов под новую [токеномику](https://serjnsk.github.io/lovix-tokenomics/): сетка Free / Premium / VIP + карточка-персонаж со слайдером (справа, после VIP), пересчёт периодов, оплата логотипами в карточках, FAQ
  - `price/index.html` — финальный макет
  - `price/SPEC.md` — спецификация для вёрстки: структура, токены (с маппингом на прод-переменные lovix.ai), контент, логика цен, слайдер, адаптив
- `assets/` — дизайн-токены (`lovix.css`), пересчёт цен (`pricing.js`), слайдер (`muse-slider.js`), фото-вырезы (`img/`)

История всех вариантов дизайна — в git. Концепт «живого виджета» (сторис-аватар в углу) одобрен для будущей системы уведомлений — код в истории (`price/v3.html` @ `1d0ff9b`).
- `assets/lovix.css` — дизайн-токены, извлечённые из продакшн-стилей lovix.ai (палитра, шрифт, радиусы) + хром сайта (сайдбар, топбар)
- `assets/pricing.js` — общий пересчёт цен по периодам (1 мес / 3 мес −10% / 1 год −20%)

## Бизнес-логика (из токеномики)

| | Free | Premium | VIP |
|---|---|---|---|
| Цена | 0 ₽ | 990 ₽/мес | 1590 ₽/мес |
| Токены | — | 300/мес | 550/мес (токен −12%) |
| Сообщения | 5/мес | 500/день | безлимит |

Транш токенов одинаков во всех периодах оплаты (правило Т10); скидка за период применяется к цене.
