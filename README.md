# Lovix Design

Редизайны страниц [lovix.ai](https://lovix.ai) под новую бизнес-логику.

**Live:** https://serjnsk.github.io/lovix-design/

## Структура

- `index.html` — хаб проекта: список страниц
- `price/` — страница тарифов под новую [токеномику](https://serjnsk.github.io/lovix-tokenomics/); `price/index.html` — компаратор: все варианты на одном URL с переключалкой (кнопки 1–5, клавиши, hash `#vN`, синхронизация периода)
  - `v1.html` — Классика: чистый лейаут, FAQ, оплата в карточках
  - `v2.html` — Амбиент-фон: лейаут v1 + девушки-слайдер вторым планом за хиро
  - `v3.html` — Девушка-колонка: sticky-слайдер слева, компактная сетка v1 справа
  - `v4.html` — Девушка в сетке: слайдер как карточка внутри сетки тарифов

Концепт «живого виджета» (сторис-аватар в углу) одобрен для будущей системы уведомлений — код в истории git (`price/v3.html` @ `1d0ff9b`).
- `assets/lovix.css` — дизайн-токены, извлечённые из продакшн-стилей lovix.ai (палитра, шрифт, радиусы) + хром сайта (сайдбар, топбар)
- `assets/pricing.js` — общий пересчёт цен по периодам (1 мес / 3 мес −10% / 1 год −20%)

## Бизнес-логика (из токеномики)

| | Free | Premium | VIP |
|---|---|---|---|
| Цена | 0 ₽ | 990 ₽/мес | 1590 ₽/мес |
| Токены | — | 300/мес | 550/мес (токен −12%) |
| Сообщения | 5/мес | 500/день | безлимит |

Транш токенов одинаков во всех периодах оплаты (правило Т10); скидка за период применяется к цене.
