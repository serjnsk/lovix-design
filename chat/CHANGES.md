# Чат с компаньоном — что изменилось относительно текущей версии

Сравнение финального макета (https://serjnsk.github.io/lovix-design/chat/) с текущей прод-страницей чата (скриншоты от 2026-08-13). Для вёрстки: это список продуктовых и UI-отличий; технические детали — в [`SPEC.md`](SPEC.md).

## Убрано (санитария интерфейса)

| Было в проде | Стало |
|---|---|
| Переключатель Roleplay/Чат в **трёх** местах: шапка, правая панель, кнопка «Чат» у поля ввода | **Один** переключатель — в шапке чата |
| Кнопка «Озвучить · 47 💎» на каждом сообщении бота (TTS) | Озвучка удалена полностью |
| Транскрипт голосовых с ремарками («лёгкий смех, шёпот в микрофон…») | Голосовое — только плеер с волной и длительностью |
| Сырая техническая ошибка в ленте («Произошла ошибка… cURL error 28… cloudfront.net/predictions/…») | Карточка «Не получилось ответить — токены вернулись на баланс» + кнопка «Повторить» |
| Техподпись «Медиа (1.29 МБ)» и заголовок-карточка «Photo» у фото | Чистое фото со скруглением и подписью от бота |
| Постоянный счётчик «0/1000» под полем | Счётчик появляется только после 800 символов |
| Кнопка «Вложения» в правой панели | Живая сетка «Медиа чата» с просмотрщиком (см. ниже) |

## Лента диалога

- Бабблы в Telegram-манере: компактные, с хвостиками; бот — тёмное стекло слева, пользователь — фирменный градиент справа.
- Roleplay-ремарки `*действия*` — приглушённым розовым курсивом (было — голубым текстом в строке).
- Индикатор **«печатает…»** перед каждым ответом бота.
- Разделители-пилюли: даты, смена режима («Режим: Roleplay»), старт сценария («Сценарий: …»).
- Переключение Roleplay/Чат **меняет фон ленты** кросс-фейдом (тёплый градиент ↔ нейтральный тёмный) — сохранено и упорядочено.
- Новые виды сообщений: **сообщение-запрос** («Запрос фото · 25 💎» + описание), **видео-сообщение** (для не-VIP — блюр + замок «Видео доступно на VIP», для VIP — постер с play).
- Шапка: «Имя, возраст» в одну строку + статус «онлайн»; **звонок переехал от поля ввода в шапку**.

## Композер (поле ввода)

- Было: узкое поле + кнопка «Чат» слева + звонок и отправка справа. Стало: **единый блок** — просторное поле сверху (в два раза выше), под ним внутри той же рамки строка действий: чипы **Фото / Голосовое / Видео `VIP` / Сценарии** + кнопка отправки.
- **Медиа-запросы структурированы** (было: пользователь выпрашивал текстом «пришли фото»):
  - клик по чипу включает режим описания (чип подсвечен, плейсхолдер «Опишите, какое фото хотите получить…»);
  - **цена показывается в кнопке отправки** («➤ 25 💎») — без ценников на каждом действии и без плашек;
  - токены списываются **после** ответа бота; отмена — повторный клик или Esc.
- **Видео — по заготовленным пресетам** (пайплайн генерации): поповер «Видео по пресету» (Танцует, Делает йогу, Воздушный поцелуй…), свободного описания нет. Только VIP.

## Сценарии «С чего начнём?»

- Развёрнутый блок — только в **новом/пустом** чате (любом: все чаты списка кликабельны и стартуют со сценариями). В идущем диалоге — чип «Сценарии» в композере (было: блок висел посреди переписки).
- Spicy-таб: перчиковая hover-анимация 🌶 (Premium/VIP); **на Free — замки** на табе и карточках, клик — пейволл подписки.

## Монетизация (новое)

- **Живой баланс токенов** в топбаре: списания с флеш-анимацией (на Free баланс скрыт — токенов у Free нет).
- **Пейволлы в ленте**, без увода со страницы: нехватка токенов («Не хватает N» + пакет/все пакеты), VIP-гейт (звонок, видео), гейт подписки (spicy, фото/голос на Free). Во все переходы передаётся точка входа для аналитики.
- Тарифные гейты сведены в матрицу — `SPEC.md` §7 (Free: 5 сообщ/мес, без медиа-запросов; Premium: фото+голос; VIP: + видео-пресеты, звонки, разлочка видео).
- VIP-плашки и замочки показываются **только тем, кому фича недоступна** (на VIP апсейл-хром скрыт).

## Правая панель (профиль)

- Порядок: фото → **имя, возраст** (+бейдж «Мой бот») → **описание** («читать далее») → **Медиа чата** → кнопки → «Обо мне».
- «Обо мне» и «Внешность» слиты в **один** список фактов с иконками (было два разнородных блока).
- **Медиа чата** — живая однострочная сетка: до 3 превью, дальше «+N» → модалка «Все медиа»; клик — полноэкранный просмотрщик с листанием (стрелки/клавиши) и счётчиком; видео-слайды гейтятся тарифом; новые фото/видео из диалога появляются в сетке сразу.
- Кнопки: «Профиль» (переименовано с «Перейти в профиль бота»); у пользовательского бота — «Перегенерировать профиль» + «Редактировать».
- Дубль переключателя режима из панели удалён.

## Список чатов

- Превью последнего сообщения сворачивает медиа в тип: «📷 Фото», «🎤 Голосовое», «🎬 Видео», запрос — иконка + описание.
- Аватары с онлайн-точкой; боты без образа — инициал / розовый бот-аватар; бейдж непрочитанных.

## Демо-механики макета (в прод не идут)

- Кнопка тарифа в топбаре с бейджем «демо» — циклер Free → Premium → VIP для проверки замков и гейтов (демо стартует с VIP, чтобы видео-пайплайн был виден сразу).
- Тосты-заглушки чекаутов и переходов.
