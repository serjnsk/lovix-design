# Чат с компаньоном — спецификация для вёрстки

Финальный макет: `chat/index.html` · live: https://serjnsk.github.io/lovix-design/chat/
Финал — вариант «Панель действий», по итогам правок: действия интегрированы внутрь композера. История отброшенных вариантов — в git.

## 1. Структура страницы

Три колонки во всю высоту вьюпорта (`.chatwrap`, страница не скроллится — скроллятся колонки):

| Зона | Ширина | Скролл |
|---|---|---|
| `.cl` — список чатов | 305px | own |
| `.cc` — чат (шапка / лента / композер) | flex 1 | лента |
| `.cp` — профиль компаньона | 305px | own |

Топбар чата: **живой баланс токенов** (`.balance`, обновляется при списаниях с флеш-анимацией) + кнопка подписки + колокольчик + аватар. Дизайн-токены и маппинг на прод-переменные — `price/SPEC.md` §2.

**Демо-переключатель тарифа**: в макете клик по кнопке подписки циклит Free → Premium → VIP (меняются замки, гейты и разлочка видео). В проде тариф приходит из профиля пользователя.

## 2. Список чатов (`.cl`)

- Шапка «Чаты» + «+» (новый чат → каталог), поиск с фильтрацией по имени.
- Элемент `.ci`: аватар 48px (фото / инициал на градиенте / розовый бот-аватар) с зелёной точкой онлайн; имя + время; превью последнего сообщения (медиа сворачивается в «📷 Фото» / «🎤 Голосовое» / «🎬 Видео», запрос — иконка + текст описания); бейдж непрочитанных `.unr`.
- Активный чат — `.ci.on`. Клик открывает чат без перезагрузки.

## 3. Шапка чата (`.cc-h`)

- Аватар + **«Имя, возраст»** + статус «онлайн».
- Справа: кнопка звонка (бейдж VIP; не-VIP — клик открывает VIP-гейт в ленте, VIP — звонок) и **единственный** переключатель режима `.mseg`: **Roleplay** (иммерсив с ремарками-действиями) / **Чат** (обычная переписка). Других мест переключения нет.
- Смена режима: разделитель «Режим: …» в ленте + **смена фона ленты** кросс-фейдом (0.8s): Roleplay — тёплый розово-фиолетовый с свечениями, Чат — нейтральный тёмный. Два absolute-слоя `.ccbg.rp`/`.ccbg.chat`, `data-mode` на `.cc`.

## 4. Лента (`.feed`) — виды сообщений

Бабблы: бот слева (`rgba(255,255,255,.075)` + blur, хвостик), пользователь справа (градиент fuchsia→rose, хвостик). `max-width: min(64%, 560px)`, появление — анимация.

| Вид | Разметка | Поведение |
|---|---|---|
| Текст | `.bub` | ремарки `*…*` — курсив `.rp-act` (приглушённо-розовый; в баббле пользователя — белый полупрозрачный) |
| Запрос медиа (пользователь) | `.bub` + шапка `.reqhead` («Запрос фото · 25 💎» / «Запрос голосового · 15 💎» / «Запрос видео · 50 💎») + описание или «Пресет: …» | фиксирует, что и за сколько запрошено |
| Фото | `.bub.mph` + `.phbox` 300×370 + подпись `.cap` | клик → лайтбокс; у ботов без образа — `.phbox.noimg` |
| Голосовое | плеер `.vc`: play, волновые бары, длительность | play анимирует прогресс; **без транскрипта** |
| Видео | `.bub.mvid` + `.vidbox` 300×190 | **не-VIP**: заблюренное превью + замок + «Видео доступно на VIP» + бейдж VIP, клик → VIP-гейт. **VIP**: чёткий постер + play (`.unlocked`), клик → плеер. Разлочка по текущему тарифу |
| Ошибка ответа | `.bub.errb`: «Не получилось ответить», «токены вернулись на баланс», «Повторить» | сценарий У3-7: возврат токенов, ретрай |
| «Печатает…» | `.m.typing` — три точки | перед каждым ответом (1.3–2.4s в демо) |
| Разделители `.dv` | дата, смена режима, «Сценарий: …» | пилюли по центру |
| Пейволлы `.payw` | по центру ленты | §7 |

Никаких сырых техстрок (размер файла, cURL и т.п.).

## 5. Композер (`.composer`) — поле и действия в одном блоке

Единый блок с рамкой (`focus-within` подсвечивает): **textarea сверху** (min-height 64px — просторная зона набора, авторасширение до 150px), **строка действий снизу** `.crow`: чипы + кнопка отправки справа.

Чипы `.qchip` (без цен — цены не дублируются у каждого действия): **Фото**, **Голосовое**, **Видео `VIP`**, **Сценарии**.

- **Фото / Голосовое — композер-режим запроса**: клик включает режим описания (не отправляет сразу):
  - чип подсвечивается `.on`, повторный клик или Esc — отмена;
  - placeholder: «Опишите, какое фото хотите получить…» / «О чём рассказать голосом? Опишите…»;
  - **цена — в кнопке отправки**: `.send.pricey` расширяется → `➤ 25 💎` / `➤ 15 💎` (стоимость видна до запуска — правило О3, без плашек);
  - отправка: сообщение-запрос → «печатает…» → медиа-ответ → **списание после ответа** (баланс в топбаре, флеш). Режим сбрасывается.
- **Видео — пайплайн по пресетам** (генерация из заготовок): для VIP клик открывает поповер «Видео по пресету» (Танцует / Делает йогу / Воздушный поцелуй / Подмигивает / С чашкой кофе / Кружится…). Выбор пресета → режим с placeholder «Видео: «Танцует» — нажмите отправить», цена в send (`➤ 50 💎`), отправка без текста → запрос «Пресет: Танцует» → видео-ответ. Свободного описания нет — только пресеты (ограничение пайплайна генерации). Для Free/Premium клик по чипу — VIP-гейт.
- **Сценарии**: чип открывает поповер-хелпер (табы Обычные / 🌶 Spicy + список) — вход в сценарии из идущего диалога. Единственный вход, дублей нет.
- Textarea: Enter — отправить, Shift+Enter — перенос, лимит 1000, счётчик с 800.
- Поповеры (`.pop`) якорятся над композером, закрываются кликом мимо / Esc.

## 6. Сценарии («С чего начнём?»)

- **Новый/пустой чат** (любой бот без истории): в ленте после приветствия — развёрнутый блок `.scen`: табы **Обычные / 🌶 Spicy** и грид 2×3 карточек.
- **Spicy — только для подписчиков**: на Free таб получает 🔒, карточки — класс `.lk` с жёлтым замком вместо шеврона и приглушённым текстом (перчиковая hover-анимация отключена); клик по запертой карточке → **пейволл подписки** («Spicy-сценарии — в подписке», CTA «Оформить подписку» → чекаут Premium). На Premium/VIP — доступно, hover по spicy-карточке сыплет перчики 🌶 (`.pep`, рандомизированные CSS-переменные).
- Выбор сценария: разделитель «Сценарий: …» → «печатает…» → вводная реплика бота (словарь `INTRO`). Блок исчезает.
- **Идущий диалог**: тот же набор через чип «Сценарии» (замки́ действуют и в поповере).
- Набор общий для каталожных и пользовательских ботов; контент — из настроек продукта.

## 7. Монетизация в чате (пейволлы `.payw`)

Все продажи «на месте» — карточкой в ленте, без увода со страницы:

| Триггер | Карточка | CTA |
|---|---|---|
| Запрос медиа при нехватке токенов | «Не хватает N токенов» + «Действие стоит X, на балансе Y. Пополните пакетом — купленные токены не сгорают» (П8–П10) | «Пакет 100 · 390 ₽» → чекаут пакета; «Все пакеты»; «Позже» |
| Звонок / видео на Free или Premium | «… — фича VIP» + допродажа (550 токенов/мес, токен −12%) (Т8) | «Перейти на VIP» → чекаут VIP с зачётом; «Позже» |
| Spicy-сценарий на Free | «🌶 Spicy-сценарии — в подписке» | «Оформить подписку» → чекаут Premium; «Позже» |

- Пейволл не блокирует чат; режим запроса при нехватке не сбрасывается (описание сохраняется).
- В переход передаётся источник: `точка входа: чат, нехватка токенов / VIP-гейт / spicy-гейт`.
- Цены операций (фото 25, голосовое 15, видео 50) — из прайс-листа настроек; в макете демо-значения.

## 8. Профиль компаньона (`.cp`)

Порядок сверху вниз:

1. **Фото** (305px, клик → лайтбокс); у ботов без образа — плейсхолдер `.ph-init` (инициал / бот-иконка на розовом градиенте).
2. **Имя, возраст** + бейдж «Мой бот» у пользовательских.
3. **Описание** (`.cp-bio`, кламп 3 строки + «читать далее/свернуть»; кнопка скрыта у коротких).
4. **Медиа чата** — живая сетка миниатюр 3 колонки: до 6 превью; если медиа больше — 5 превью + тайл **«+N»**, открывающий модалку **«Все медиа»** (заголовок с количеством, полная сетка 4 колонки). Видео-тайлы — кружок play (VIP) или замка (не-VIP). Клик по любой миниатюре — **полноэкранный просмотрщик-галерея**: листание стрелками и клавишами ←/→ по кругу, счётчик «i / N», Esc/фон/✕ — закрыть (слоями: сначала просмотрщик, потом модалка). Фото показывается целиком; видео-слайд — заблюренный кадр + play (VIP → плеер) или замок + «Видео доступно на VIP» + CTA «Перейти на VIP» (не-VIP). Новые фото/видео из диалога добавляются в сетку первыми. Пусто → «Фото и видео из диалога появятся здесь». Одиночные фото (клик по фото в ленте или портрету бота) открываются в том же просмотрщике без стрелок и счётчика.
5. **Кнопки**: каталожный — «Профиль»; пользовательский — «Перегенерировать профиль» + «Редактировать».
6. **Обо мне** — список фактов `.fact` (иконка + ярлык + значение): личность, отношение, профессия, хобби, фетиши, рост, телосложение, этничность — сколько есть.

## 9. Адаптив

- ≤1280 — профиль скрывается (открытие — тапом по шапке чата, шторкой справа).
- ≤1000 — список чатов скрывается (вход со страницы «Мои чаты», назад — стрелкой в шапке).
- Мобайл: чипы композера скроллятся горизонтально; лента full-width; список и профиль — отдельные экраны.

## 10. Интеграция и данные

- **Тариф пользователя** (`free/premium/vip`) определяет: доступ к Spicy (Free — замки), звонок и видео (только VIP), разлочку видео-сообщений в истории. В макете — демо-циклер на кнопке подписки.
- **Демо-данные**: `BOTS` (Александра — каталожная, Roleplay, лента со всеми видами сообщений; Персональный бот — пользовательский; 8 стабов с новыми чатами), `SCEN`/`INTRO`, `REQ` (цены запросов), `VIDEO_PRESETS`, `POOL`. В проде — из API.
- **Баланс** — источник истины сервер; списание после успешного ответа (сбой — возврат, У3-7).
- **Режим общения** — свойство диалога, персистится.
- Непрочитанные чаты ↔ бейдж «Мои чаты»; проактивы компаньонов приходят виджетом (`notifications/FLOWS.md` Флоу 8), в открытом чате — обычным сообщением.
- Хром (сайдбар/топбар) — продовый, верстается контент-зона.

### Аналитика (клиентские события)

- `chat.opened` (id бота, catalog/own, новый/идущий)
- `chat.message_sent` (режим rp/chat)
- `chat.mode_switched`
- `chat.media_request_started` / `chat.media_request_sent` / `chat.media_request_cancelled` (тип, цена)
- `chat.video_preset_selected` (пресет)
- `chat.scenario_opened` / `chat.scenario_started` (таб, id сценария)
- `chat.retry_clicked`
- `paywall.shown` / `paywall.cta_clicked` (тип: tokens / vip / subscription; точка входа)
