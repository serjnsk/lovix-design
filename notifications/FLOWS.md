# Центр уведомлений Lovix — юзерфлоу

Финальный макет: https://serjnsk.github.io/lovix-design/notifications/ (все флоу кликабельны, симулятор внизу страницы).
Основа: документы [«События»](https://serjnsk.github.io/lovix-tokenomics/events.html) и [«Сценарии взаимодействия»](https://serjnsk.github.io/lovix-tokenomics/scenarios.html).

**Ключевое решение:** отдельная страница уведомлений упраздняется — весь центр живёт в дропдаун-панели у колокольчика (400px, якорь под иконкой). Пользователь не теряет контекст текущей страницы.

**Роль канала:** колокольчик — канал сопровождения (доставляет, когда пользователь в продукте), без квот и тихих часов; идут все уведомления, Т и М. Проактивы компаньонов (💬) в колокольчик не попадают — их непрочитанное живёт в «Мои чаты».

---

## Анатомия панели

Сверху вниз:
1. **Шапка**: «Уведомления · N новых» + действия: «прочитать все» (✓✓), настройки (⚙).
2. **Критичный блок** (если активен) — закреплённое уведомление окна восстановления, не скроллится с лентой.
3. **«Новые»** — непрочитанные, свежие сверху.
4. **«Ранее»** — прочитанные.
5. **«Показать ещё»** — подгрузка старой истории.
6. Пустое состояние, когда список пуст: «Пока тихо — уведомлений нет».

Бейдж на колокольчике = число непрочитанных (включая критичное); свыше девяти — «9+».

---

## Флоу 1. Открытие и чтение

1. Клик по колокольчику → панель открывается на месте (страница под ней не меняется).
2. Клик по уведомлению → помечается прочитанным: фон и точка гаснут, элемент уходит в «Ранее», бейдж −1.
3. «Прочитать все» (✓✓) → все непрочитанные гаснут разом; критичное закреплённое **не** сбрасывается (см. Флоу 5).
4. Закрытие: клик вне панели / Esc / повторный клик по колокольчику.

Открытие панели само по себе ничего не помечает — прочтение только явным кликом (пользователь мог не увидеть список ниже сгиба).

## Флоу 2. Прилёт нового уведомления (real-time)

Пользователь в продукте, происходит событие (например, `tokens.balance_low`):

1. Бейдж увеличивается с анимацией-пульсом — единственный сигнал, никаких тостов и звуков (канал сопровождения, не прерывания).
2. Если панель открыта — уведомление вставляется наверх группы «Новые» с короткой подсветкой фона.
3. Повторная доставка того же события дубль не создаёт (С3).

## Флоу 3. Действие из уведомления → конверсия (Д2)

У актуальных уведомлений — одна CTA-кнопка с маршрутом к целевому действию:

| Сценарий | Уведомление | CTA | Маршрут |
|---|---|---|---|
| У2-7 `tokens.balance_low` | Токены на исходе | Пополнить токены | чекаут пакета (страница/оверлей пакетов) |
| У2-8 `tokens.expiring_soon` | Остаток сгорит через N дней | — | информационное |
| У2-3 `message_limit.reached` (premium) | Дневной лимит исчерпан | Перейти на VIP | чекаут VIP с зачётом |
| У2-4 `message_limit.reached` (vip) | Дневной предел | — | без апсейла (тарифа выше нет) |
| У3-2 `payment.failed` | Платёж не прошёл | Повторить оплату | чекаут со сменой способа (recovery-петля) |
| У3-7 `operation.failed` | Сбой операции, токены возвращены | Попробовать снова | повтор операции |
| У3-4 `subscription.started` | Добро пожаловать в Premium | — | информационное |
| У3-5 `subscription.upgraded` | VIP включён | — | информационное |
| У6-5 `subscription.reactivated` | Токены разморожены | — | информационное |
| У1-2 / промо | Приветствие, новости | — / опционально | каталог / анонс |

Правила:
- Клик по CTA = конверсионное действие: уведомление помечается прочитанным, кнопка заменяется статусом **«✓ Готово»** — серия сценария остановлена (Д2), уведомление остаётся в истории как факт.
- Если целевое действие совершено в обход уведомления (купил пакет сам), при следующем открытии панели CTA тоже показывается как «✓ Готово» — состояние сверяется с сервером, кнопка никогда не ведёт на уже сделанное.
- В переход передаётся источник (`точка входа: колокольчик, сценарий УX-X`) — для аналитики конверсии точек продажи.

## Флоу 4. Управление уведомлением

Hover по уведомлению → в правом верхнем углу появляются быстрые действия:
- **Прочитано / вернуть в непрочитанные** — переключатель (✓ / ●). Возврат в непрочитанные возвращает элемент в «Новые» и увеличивает бейдж («прочитаю позже»).
- **Удалить** (корзина) — элемент исчезает, показывается тост «Уведомление удалено · **Вернуть**» (5 секунд на undo). Удаление скрывает уведомление у пользователя, из аналитики ничего не удаляется.

На таче hover-действий нет: чтение — тапом, удаление — свайпом влево (та же пара действий под свайпом: прочитано/удалить).

## Флоу 5. Критичное закреплённое (окно восстановления, У4)

События `subscription.past_due_started` (день 0) и `subscription.grace_started` (день 1) создают **закреплённый блок** над лентой:

- Выделен градиентной янтарно-розовой рамкой, содержит: заголовок, объяснение («токены и компаньоны сохранены»), **таймер** «До перехода на Free — N дней» и CTA «Оплатить сейчас».
- Не удаляется, не помечается прочитанным, не сбрасывается «прочитать все» — снимается только решением: успешная оплата (recovery) или наступление дня 4 (тогда заменяется обычным уведомлением `reverted_to_free` о заморозке токенов).
- Пока блок активен, бейдж на колокольчике не опускается ниже 1.
- Таймер обновляется по дням (день 0 → 1 → 3), текст соответствует шагу окна из токеномики.

Одновременно активен максимум один критичный блок (состояния окна взаимоисключающие).

## Флоу 6. Настройки категорий (Д7)

Шестерёнка в шапке → подэкран настроек **внутри той же панели** (не отдельная страница), «←» возвращает к списку:

- **Транзакционные** — переключатель заблокирован во «вкл» (платежи, доступ, токены неотключаемы).
- **Продажи и предложения** (У2-1…У2-8) — отключаемо.
- **Новости и вовлечение** (промо, обновления) — отключаемо.

Изменение действует мгновенно: выключенная категория перестаёт доставляться в колокольчик (уже полученные остаются в истории). Настройка не влияет на email — у него собственная отписка категориями.

## Флоу 7. История, «Показать ещё», пустое состояние

- Панель держит последние ~30 уведомлений; глубже — кнопка «Показать ещё» порциями.
- Ретеншн истории — 90 дней, старше вычищается (история — сопровождение, не архив).
- Пустое состояние (всё удалено / новый пользователь без событий): иконка колокольчика + «Пока тихо — уведомлений нет».

## Бейдж: сводные правила

| Событие | Бейдж |
|---|---|
| Доставка уведомления | +1, пульс-анимация |
| Клик по уведомлению / CTA | −1 |
| «Прочитать все» | 0 (плюс 1, если активен критичный блок) |
| Возврат в непрочитанные | +1 |
| Удаление непрочитанного | −1 |
| Больше 9 | «9+» |

## Edge cases

- **Дубли**: повторная доставка события не создаёт второй элемент (С3) — ключ идемпотентности = ID события.
- **Локаль**: тексты в языке локали пользователя (Д6).
- **Накопленное за офлайн**: при входе всё ждёт в панели (канал без капов) — бейдж честный, лента отсортирована по времени.
- **Уведомление об устаревшем состоянии**: CTA всегда сверяется с текущим состоянием (см. Флоу 3) — «Пополнить токены» после покупки пакета показывается как «✓ Готово».
- **Смена тарифа**: видимость новых уведомлений соответствует текущему тарифу; старые остаются как история.

## Аналитика взаимодействий (клиентские события 🖱)

- `bell.opened` — открытие панели (+ число непрочитанных на момент открытия)
- `notification.read` — прочтение (id сценария, способ: клик / прочитать все)
- `notification.cta_clicked` — клик CTA (id сценария → знаменатель конверсии колокольчика)
- `notification.dismissed` — удаление (+ undo да/нет)
- `notification.category_toggled` — переключение категории (какая, вкл/выкл)
- `notification.more_loaded` — подгрузка истории

## Для вёрстки

- Компоненты переиспользуют дизайн-систему тарифов: `assets/lovix.css`, токены — `price/SPEC.md` §2.
