# Страница тарифов Lovix — спецификация для вёрстки

Финальный макет: https://serjnsk.github.io/lovix-design/price/ (исходник — `price/index.html` в этом репо).
Бизнес-логика согласована с токеномикой: https://serjnsk.github.io/lovix-tokenomics/

Макет включает хром сайта (сайдбар, топбар) только для контекста — верстается **контент-зона** страницы подписки, хром берётся продовый.

---

## 1. Структура страницы

1. **Хиро** — h1 «Откройте новые грани общения с Lovix» + подзаголовок «Больше действий. Больше эмоций. Ещё ближе.» По центру.
2. **Переключатель периодов** — сегмент-контрол: `1 месяц` / `3 месяца −10%` / `1 год −20%`. По центру. Активный сегмент — градиентная пилюля.
3. **Сетка тарифов** — 4 колонки `repeat(3, 1fr) 250px`, gap 16px:
   Free → Premium → VIP → **карточка-персонаж со слайдером** (всегда последняя, после VIP).
4. **FAQ** — 4 сворачиваемых вопроса (`details/summary`), max-width 860px по центру. Никаких подписей-дисклеймеров под FAQ нет.

## 2. Дизайн-токены

Все значения уже существуют в продакшн-CSS lovix.ai — использовать их переменные:

| Макет (`assets/lovix.css`) | Прод lovix.ai | Значение |
|---|---|---|
| `--page` | `--color-page` | `34 31 34` |
| `--page-from` | `--color-page-gradient-from` | `37 54 107` |
| `--surface` | `--color-surface` | `19 16 19` |
| `--overlay` | `--color-overlay` | `16 14 16` |
| `--muted` | `--color-muted` | `163 163 180` |
| `--muted2` | `--color-muted-strong` | `128 128 140` |
| `--acc-from` / `--acc-to` | `--color-accent-from` / `--color-accent-to` | `217 70 239` / `244 63 94` |

| `--r` | `--radius` | `.7rem` |

Шрифт — продовый Proxima Nova (в макете фолбэк Mulish только для превью). Акцентные элементы (CTA, активный сегмент, бейдж, рамка VIP) — градиент `90–135deg, accent-from → accent-to` со свечением `rgba(217,70,239,.4–.5)`.

## 3. Карточки тарифов

Общее: фон `rgba(16,14,16,.55)` + `backdrop-filter: blur(8px)`, рамка `rgba(255,255,255,.1)`, радиус `1.1rem`, flex-колонка, CTA прижата книзу (`margin-top: auto`).

Состав карточки сверху вниз: имя → слоган → цена (`2.1rem`, 800) + `/мес` → строка итога периода → **токен-бокс** → список фич → CTA → платёжные чипы.

- **Токен-бокс**: плашка с градиентом `120deg rgba(147,51,234,.3) → rgba(217,70,239,.13)`, рамка `rgba(217,70,239,.28)`, кристалл-SVG, жирный заголовок + серая подпись. У Free — приглушён (`opacity: .45`), текст «Без токенов / доступны на платных тарифах».
- **VIP-выделение**: градиентная рамка 1.5px (padding-box/border-box приём), свечение `0 0 55px rgba(217,70,239,.2)`, бейдж-пилюля «Максимум Lovix» по центру верхней кромки. Список начинается строкой «✦ Всё из Premium, плюс:» (розовая, 700).
- **Тултип** у «Групповые чаты»: кнопка `?` 17px, по hover/focus — тёмный бокс 240px: «Общение с несколькими компаньонами в одном чате — они видят реплики друг друга.»
- **Платёжные чипы** (только Premium и VIP, под CTA): светлые плашки 42×27, радиус 6px, логотипы Visa / Mastercard / МИР / BTC / USDT. В макете — инлайн-SVG (см. симболы `#p-*`); в проде можно заменить брендовыми SVG-ассетами. У Free чипов нет.

Контент карточек (тексты зафиксированы токеномикой):

| | Free | Premium | VIP |
|---|---|---|---|
| Слоган | Познакомиться с компаньонами | Полноценное общение и генерация фото | Без ограничений: видео, звонки и лучшая модель |
| Токен-бокс | — | **300 токенов каждый месяц** · на фото и аудио | **550 токенов каждый месяц** · токен на 12% дешевле, чем в Premium |
| Фичи | ✓ 5 сообщений в месяц · ✓ Каталог компаньонов · — Создание компаньонов · — Генерация фото · — Аудио сообщения | ✓ 500 сообщений в день · ✓ Создание своих компаньонов · ✓ Генерация фото · ✓ Аудио сообщения · ✓ Докупка токенов пакетами | Всё из Premium, плюс: ✓ Продвинутая нейромодель Lovix 2.0 · ✓ Безлимитные сообщения · ✓ Генерация видео · ✓ Аудио звонки · ✓ Групповые чаты (?) |
| CTA | Начать бесплатно (outline) | Выбрать Premium (outline) | Выбрать VIP (градиент + свечение) |

## 4. Цены и пересчёт периодов (`assets/pricing.js`)

Параметры из токеномики: `PREMIUM_PRICE_1M = 990`, `VIP_PRICE_1M = 1590`, скидки −10% (3 мес) / −20% (год). **Транш токенов не зависит от периода** (правило Т10) — при переключении меняются только цены.

| Период | Premium | VIP | Строка под ценой |
|---|---|---|---|
| 1 месяц | 990 ₽/мес | 1 590 ₽/мес | «оплата раз в месяц» |
| 3 месяца | 890 ₽/мес | 1 430 ₽/мес | «2 670 ₽ за 3 месяца · **экономия 300 ₽**» / «4 290 ₽ за 3 месяца · **экономия 480 ₽**» |
| 1 год | 790 ₽/мес | 1 272 ₽/мес | «9 490 ₽ за год · **экономия 2 390 ₽**» / «15 260 ₽ за год · **экономия 3 820 ₽**» |

Механика в макете: кнопки `[data-period="m1|m3|y1"]`, цены в `[data-pm="premium|vip"]`, строка итога в `[data-total]`. Форматирование чисел `toLocaleString('ru-RU')` (неразрывные пробелы). «Экономия» выделена розовым `#f0abfc`. Free всегда «0 ₽ / навсегда бесплатно».

CTA при интеграции передаёт в чекаут **тариф + выбранный период**.

## 5. Карточка-персонаж со слайдером (`assets/muse-slider.js`)

Размер: колонка 250px, `min-height 420px`, радиус `1.1rem`. Фон — градиент `160deg card-from → card-to` + розовые радиальные блики. Поверх фона:

- **Слайды** — фото-вырезы персонажей с прозрачным фоном (`object-fit: contain; object-position: bottom center`), кроссфейд `opacity .5s`.
- **Оверлей** (::before, z-index 1): виньетка сверху `rgba(16,14,16,.5) → 0 за 20%` и снизу `0 → .92` — читаемость шапки и бабблов.
- **Шапка** (абсолют, верхний левый угол): круглый аватар 40px с градиентным кольцом + **имя (синхронизируется со слайдом)** + зелёная точка «онлайн».
- **Бабблы** (внизу): «Хочешь поиграть со мной? 😈» (слева) и «Не могу перестать думать о тебе… 😏» (справа, зеркальный радиус) — тёмные `rgba(10,8,12,.82)`, курсив.
- **Подпись**: «Выбери тариф — я рядом 💕» (розовая, по центру).
- **Управление**: стрелки ‹ › 28px по бокам (видны по hover карточки), точки-индикаторы под подписью (активная — вытянутая белая пилюля 16px).

Поведение: автоплей 5000 мс, пауза при hover, клик по стрелке/точке перезапускает таймер. Данные слайда — `data-name` на `<img>` (в проде — имя реального персонажа), имя подставляется в `[data-muse-name]`. В проде фото и имена приходят из каталога компаньонов; формат фото — webp-вырез с альфой, ~400×861 (в макете `assets/img/model-1.webp` Алиса, `model-2.webp` Майя, по ~40 КБ).

## 6. FAQ

4 вопроса `details/summary`, плюсик `+` справа поворачивается на 45° при открытии. Тексты (согласованы с токеномикой, менять только вместе с ней):

1. **Что такое токены?** — Токены — внутренняя валюта Lovix для медиа-действий: генерации фото и видео, аудио сообщений и звонков. Текстовые сообщения токены не расходуют — у них свои лимиты по тарифу.
2. **Сгорают ли токены?** — Тарифные токены приходят каждый месяц и действуют до конца месячного цикла. Токены, купленные пакетами, не сгорают никогда.
3. **Что, если токены закончатся?** — На Premium и VIP можно докупить пакет токенов в любой момент — или перейти на VIP, где токенов больше, а каждый токен дешевле.
4. **Меняется ли количество токенов при оплате за год?** — Нет. Объём токенов одинаков при любом периоде: 300 в месяц на Premium и 550 на VIP. Длинный период даёт скидку на цену подписки.

## 7. Адаптив

| Брейкпоинт | Поведение |
|---|---|
| ≤ 1230px | Сетка → 3 колонки; карточка-персонаж растягивается на всю ширину ряда снизу (после тарифов), `min-height 230px`, бабблы ограничены 480px |
| ≤ 940px | Одна колонка (max-width 460, по центру), порядок: Free → Premium → VIP → персонаж |

Переключатель периодов на узких экранах уменьшает паддинги (см. `assets/lovix.css`, media 640).

## 8. Ассеты и файлы макета

- `price/index.html` — финальная страница (инлайн-стили секции + спрайт SVG-иконок и платёжных логотипов)
- `assets/lovix.css` — токены + общие компоненты (кнопки, сегмент, карточка, токен-бокс, тултип)
- `assets/pricing.js` — пересчёт цен по периодам
- `assets/muse-slider.js` — слайдер персонажа
- `assets/img/model-1.webp`, `model-2.webp` — фото-вырезы (плейсхолдеры; в проде — реальные персонажи)

## 9. Что учесть при интеграции (за рамками вёрстки)

- CTA ведут в чекаут с параметрами тарифа и периода; Free — регистрация.
- Страница — для новой сетки тарифов. Действующие подписчики на Legacy-тарифе её не видят / видят со своим тарифом (миграция — раздел 10 токеномики).
- Цены операций в токенах (`PHOTO_COST` и т.д.) на странице не показываются — прайс-лист операций живёт в приложении (правило О4).
- Аналитика: события на переключение периода, клики CTA по тарифам, взаимодействие со слайдером — по вкусу продукта.
